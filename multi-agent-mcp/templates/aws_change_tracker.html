Tips for better results
  • Use the exact resource name as shown in the console (S3 bucket names are case-sensitive).
  • CloudTrail lookup_events allows one lookup attribute; this tool uses ResourceName, then filters by account and resource type.
  • Run the app with IAM credentials that have cloudtrail:LookupEvents in the trail region.
  • If you see zero rows, try a shorter lookback or confirm the resource had API activity in that region.

About this tool

This page is independent from the main OneView chat. It calls AWS CloudTrail LookupEvents in the region you specify, using the default credential chain (environment role, profile, etc.).

No data is stored on the server beyond normal request logs; CSV analysis is done in memory and returned as JSON.
