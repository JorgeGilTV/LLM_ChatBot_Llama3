About this tool

CloudTrail tab — LookupEvents by resource name. IAM: cloudtrail:LookupEvents.

Connect tab — live metrics via Connect API + CloudTrail admin/login events. Configure in .env:

  • AWS_CONNECT_INSTANCE_ID — required
  • AWS_CONNECT_REGION — defaults to AWS_REGION
  • AWS_CONNECT_AGENT_BASELINE_COUNT — expected registered users
  • AWS_CONNECT_AGENT_DROP_PCT — alert if count drops by this % (default 7.5)
  • AWS_CONNECT_LOGIN_FAIL_THRESHOLD / AWS_CONNECT_LOGIN_FAIL_WINDOW_MIN
  • AWS_CONNECT_EXPECTED_USERS — comma-separated usernames for roster compare
  • AWS_CONNECT_QUEUE_IDS — optional queue ARNs (else auto-lists queues)
  • Genesis — GENESIS_AZUREAD_SYNC_LAMBDA=AzureADSync, GENESIS_SSO_IDP_NAME=Azure_Genesis_SSO, GENESIS_SSO_ROLE_NAME=Azure_Genesis_SSO_Role, GENESIS_CONNECT_INSTANCE_ALIAS=genesis-connect

IAM: Connect APIs above + cloudwatch:GetMetricStatistics, cloudtrail:LookupEvents (lambda/sts/iam/connect).
